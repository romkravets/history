# Форма «Знаєте, що на фото? / Надіслати своє фото»

Кнопки на сторінках галерей і в лайтбоксі відкривають Google Form, у якій уже
заповнені назва галереї, номер і підпис фото та адреса сторінки. Відповіді
збираються в Google Таблиці. Поки форма не налаштована, кнопок на сайті немає.

## 1. Створити форму (5 хв)

[forms.google.com](https://forms.google.com) → «Порожня форма». Поля:

| Поле | Тип | Обов'язкове |
|---|---|---|
| Галерея | Коротка відповідь | ні (заповнюється автоматично) |
| Фото | Коротка відповідь | ні (заповнюється автоматично) |
| Адреса сторінки | Коротка відповідь | ні (заповнюється автоматично) |
| Що ви знаєте про це фото? (місце, рік, люди, історія) | Абзац | так |
| Ваше фото (необов'язково) | Завантаження файлу | ні |
| Як вас підписати на сайті? | Коротка відповідь | ні |
| Контакт для зв'язку (email / телефон) | Коротка відповідь | ні |

> Поле «Завантаження файлу» вимагає, щоб відвідувач увійшов у Google-акаунт,
> а файли падають на ваш Google Диск. Якщо не хочете цього — приберіть поле
> й попросіть надсилати фото на пошту чи в Telegram у тексті форми.

У «Відповіді» → «Зв'язати з Таблицями», щоб відповіді збиралися в таблицю.

## 2. Дізнатися id полів

Форма → ⋮ → **«Отримати попередньо заповнене посилання»** → впишіть у три перші
поля будь-що (`AAA`, `BBB`, `CCC`) → «Отримати посилання» → «Копіювати».
Посилання виглядатиме так:

```
https://docs.google.com/forms/d/e/1FAIpQL…/viewform?usp=pp_url&entry.111=AAA&entry.222=BBB&entry.333=CCC
```

## 3. Вписати в `src/site.config.ts`

```ts
feedback: {
  formUrl: "https://docs.google.com/forms/d/e/1FAIpQL…/viewform",
  fields: { gallery: "entry.111", photo: "entry.222", url: "entry.333" },
},
```

Або просто надішліть це посилання ШІ-агенту — він впише сам.
