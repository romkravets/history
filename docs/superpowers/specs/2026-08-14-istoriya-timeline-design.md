# Сторінка «Історія» (таймлайн) + дрібне полірування

Дата: 2026-08-14

## Контекст

Сайт `history` (Astro + Markdown + GitHub Pages) уже має:
- повністю українську мову (`lang="uk"`, весь UI);
- галерею фотографій на головній (`#gallery`);
- виправлений `.hero` (grid-колонка `1fr` не стискалась через відсутній `min-width: 0`, через що на широких Mac-екранах заголовок вилазив за межі блока — виправлено в `src/styles/global.css`, білд перевірено).

Лишається головне: нова сторінка «Історія» з наративом про Кременець, зібраним із підтверджених джерел, у вигляді таймлайну — плюс невеликий фільтр у галереї.

## Джерела (ядро, підтверджено користувачем)

1. history.kremenets.net.ua — розділ блогу історії + стаття про археологію
2. kremdiaz.com — некрополі Кременця
3. irp.te.ua — військовий цвинтар калантарів; козацько-п'ятницький цвинтар
4. zabytki.in.ua/uk/opis/?c=kremenets — каталог пам'яток
5. teren.in.ua — аерофоторепортаж «Кременець з висоти пташиного польоту»
6. forum.zamki-kreposti.com.ua — тема про перші кам'яні укріплення замку
7. zamki-kreposti.com.ua — городище Антонівці
8. kremenec.at.ua/publ — місцеві публікації
9. uk.wikipedia.org — Тадеуш Єжи Стецький
10. commons.wikimedia.org — Ботанічний сад у Кременці
11. fbc.pionier.net.pl — «Ілюстрований провідник по Волині»
12. dir.icm.edu.pl — польський цифровий архів, пошук «Krzemieniec»
13. hroniky.com — палаци Волині, Великі Бережці
14. kolokray.com — гора Уніяс

Другорядні джерела (LiveJournal-мандрівки, старі карти) — свідомо не використовуються в цьому циклі.

Спосіб роботи з джерелами: пряме читання через `WebFetch` (без підагентів-посередників, щоб не спотворити факти), синтез оригінального тексту українською, обережні формулювання там, де джерела розходяться або факт непевний. Вигадувати конкретику (дати, цифри, імена) заборонено — якщо джерело мовчить, сторінка теж мовчить.

## Контент-модель

Нова колекція `src/content/history/*.md` (за зразком `photos/`), одна епоха — один файл:

```md
---
order: 2
era: "lithuanian"
title: "Литовська доба"
period: "XIV–XVI ст."
summary: "Короткий підзаголовок епохи."
sources:
  - title: "Назва джерела"
    url: "https://..."
---

Наративний текст цієї епохи (Markdown).
```

Епохи (order 1..6):
1. Заснування та ранні згадки
2. Литовська доба (ВКЛ)
3. Річ Посполита
4. Австрійська й Російська влада (XIX ст.)
5. XX століття
6. Сьогодення

`content.config.ts` доповнюється схемою колекції `history` (zod: order, era, title, period, summary, sources[], body).

## Сторінка `/istoriya/`

`src/pages/istoriya.astro`: читає колекцію `history`, сортує за `order`.

Вертикальний таймлайн у стилі сайту (JetBrains Mono/Unbounded, темна тема, акцент `--accent`):
- зверху — hero-заголовок сторінки («ІСТОРІЯ МІСТА») в стилі головного hero;
- sticky міні-нав з чіпсами-епохами (як `.top-nav`), клік → скрол до вузла;
- сама стрічка: вертикальна лінія зліва (`border-left` акцентного кольору) з вузлами-мітками (квадрат, як `.brand-dot`) на кожній епосі; праворуч від вузла — картка епохи: великий period-лейбл у стилі `.meta-strip` (напр. `[XIV–XVI СТ.]`), заголовок, текст, і невеликий блок «Джерела» зі списком посилань саме цієї епохи;
- на мобільних (`≤720px`) — та сама вертикальна лінія, картки на всю ширину (таймлайн природно стається одноколонковим, окремого fallback-макета не треба);
- секція «Усі джерела» внизу сторінки — повний список 14 посилань.

Нових CSS-класів: `.timeline`, `.timeline-node`, `.timeline-era`, `.era-period`, `.era-nav` — додаються в `global.css`, той самий дизайн-токен-набір (`--accent`, `--border-c`, `--stripe`), без нових кольорів.

## Навігація

`Layout.astro`: у `.top-nav` додається `[02] ІСТОРІЯ` → `/istoriya/`, поруч із наявним `[01] ГАЛЕРЕЯ`.

## Галерея — фільтр за десятиліттям

На головній над `#gallery` — рядок чіпсів-фільтрів за `decade` (виводяться з наявних фото, без нових залежностей). Клік по чіпсу — client-side фільтрація карток (invisible/visible через `data-decade` атрибут + невеликий inline `<script>`, як уже є `.scroll-progress` скрипт у `Layout.astro`). Без бібліотек, без перебудови структури карток.

## Що НЕ входить у цей цикл

- Другорядні джерела (LiveJournal, старі карти) — не використовуються.
- Фільтр за містом у галереї — тільки за десятиліттям цього разу (YAGNI, можна додати пізніше тим самим патерном).
- Lightbox/модалка для фото — не чіпаємо, перехід на сторінку фото вже працює.

## Валідація

`npm run check` + `npm run build` після кожного етапу (колекція → сторінка → нав → фільтр). Комміт — тільки за окремим підтвердженням користувача.
