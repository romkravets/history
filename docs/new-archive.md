# Як розгорнути такий архів для свого міста чи регіону

Покрокова інструкція: від копії репозиторію до живого сайту з першою галереєю.
Розраховано на людину, яка вміє користуватися терміналом, але не обов'язково
програміста. Займає приблизно 30–60 хвилин.

> Приклад готового сайту: https://history-kremenets.vercel.app

---

## Що вийде

- Головна з банером, фільтром епох і галереями фото.
- Сторінка кожної галереї з лайтбоксом, підписами, переходом між галереями,
  кнопками «Поділитися».
- **Карта** місць, де зроблені фото.
- **Люди** — біографії відомих людей краю.
- **Бібліотека** — книги, статті, сайти, архіви про край.
- **Історія** — хронологія міста.
- SEO для Google і ШІ-пошуку, прев'ю в соцмережах.
- Безкоштовний хостинг на Vercel.

## Що потрібно

| | Навіщо | Де взяти |
|---|---|---|
| Акаунт GitHub | зберігати код і фото | github.com |
| Акаунт Vercel | безкоштовний хостинг | vercel.com (вхід через GitHub) |
| Node.js ≥ 22.12 | збирати сайт | nodejs.org |

## Крок 1. Скопіювати шаблон

На GitHub натисніть **Fork** (або **Use this template**) у репозиторії
`romkravets/history`, назвіть свій, наприклад `berezhany-archive`. Потім:

```bash
git clone https://github.com/<ви>/berezhany-archive.git
cd berezhany-archive
git lfs install
npm install
```

> Фото Кременця з LFS завантажувати не обов'язково — на кроці 2 вони
> видаляються. Якщо хочете їх побачити: `git lfs pull`.

## Крок 2. Налаштувати під своє місто — одна команда

```bash
npm run template:init -- --clean
```

Команда запитає:

| Питання | Приклад |
|---|---|
| Головне місто чи село | Бережани |
| Родовий відмінок («історія …») | Бережан |
| Орудний відмінок («пов'язані з …») | Бережанами |
| Назва краю (можна пропустити) | Бережанщина |
| Край у родовому відмінку | Бережанщини |
| Область | Тернопільська |
| Назва сайту | Історичний архів Бережанщини |
| Адреса сайту | https://berezhany-archive.vercel.app |
| Автор | ваше ім'я і посилання |

Координати міста знаходяться автоматично в OpenStreetMap. Усе записується в
`src/site.config.ts` — його можна потім правити вручну.

`--clean` видаляє галереї, фото, історію, людей і бібліотеку Кременця й додає
**по одному прикладу** кожного типу, щоб сайт одразу збирався. Без `--clean`
змінюються лише назва й тексти (корисно, щоб спершу подивитися).

Перегляньте результат:

```bash
npm run dev     # http://localhost:4321
```

## Крок 3. Замінити оформлення

- **Відео банера** — `public/video/banner.mp4` і `banner.webm` (10–20 с, без
  звуку, ≤ 3 МБ, 1280–1920 px завширшки) і кадр-заставка `banner-poster.jpg`.
  Підійде відео з дрона, панорама міста чи повільний проліт над старими фото.
  Конвертація: `ffmpeg -i in.mov -an -vf scale=1600:-2 -c:v libx264 -crf 28 banner.mp4`
  і `ffmpeg -i in.mov -an -vf scale=1600:-2 -c:v libvpx-vp9 -crf 40 -b:v 0 banner.webm`.
- **Кольори** — CSS-змінні на початку `src/styles/global.css` (`--accent` —
  головний акцентний колір). Тримайте контраст тексту ≥ 4,5:1.
- **Значок сайту** — `public/favicon.svg`, `public/favicon.ico`.
- **Сторінка «Про архів»** — `src/pages/about.astro`: розділи «Автор» і «Як це
  зроблено» опишіть про себе.

## Крок 4. Перший контент

**Галереї фото.** Видаліть приклад (`src/content/photos/example-gallery.md` і
`public/photos/example-gallery/`) і додайте власні:

- вручну — README → «Додати фото вручну»;
- з ШІ — README → «Робота з ШІ покроково»: дайте Claude Code шлях до папки з
  фото, і він перевірить дублікати, розсортує, напише описи й підписи.

**Історія.** Файли `src/content/history/01-…md`, `02-…md` — одна епоха = один
файл (формат — у README).

**Люди.** `src/content/people/<прізвище>.md` — поля `name`, `born`, `died`,
`role`, `connection` (одне речення про зв'язок із краєм), `places`,
`galleries` (slug пов'язаних галерей), `sources`; текст файлу — біографія.
Портрет — `portrait: "/photos/people/<файл>.jpg"`, або без нього (буде
монограма з ініціалів).

**Бібліотека.** `src/content/library/<назва>.md` — `title`, `author`, `year`,
`type` (книга / стаття / художній твір / архів/збірка / сайт / відео),
`description`, `url` (де читати), `people` (slug людей).

Підказка для ШІ: «Знайди 10 відомих людей, пов'язаних із <містом>, з
перевіреними джерелами, і створи файли в src/content/people» або «Склади
бібліотеку краєзнавства <міста>: книги, статті, сайти — тільки з
посиланнями, які відкриваються».

Перевірка:

```bash
npm run check   # 0 errors
npm run build
```

## Крок 5. Інструкції для ШІ

Відкрийте `AGENTS.md` (на нього вказує `CLAUDE.md`) і замініть згадки
Кременця. Там же правила: мова описів, обов'язкові джерела, авторські права.
Розділи про віддалений LLM-сервер можна видалити — вони потрібні лише автору
оригіналу.

## Крок 6. Публікація

1. Закомітьте й запуште:
   ```bash
   git add -A
   git commit -m "Архів <міста>: налаштування й перші галереї"
   git push
   ```
2. **vercel.com → Add New → Project** → оберіть репозиторій → **Deploy**.
   Налаштування збірки Vercel визначить сам (Astro).
3. **Settings → Git → Git LFS → Enabled** — інакше фото не потраплять на сайт.
   Після цього зробіть **Redeploy**.
4. **Settings → Deployment Retention**: production — 30 днів, решта — 1 день /
   тиждень. Без цього кожен пуш з'їдає сховище (кожен деплой містить усі фото).
5. Якщо адреса інша, ніж у `site.config.ts`: **Settings → Environment Variables**
   → `SITE_URL = https://ваша-адреса` → Redeploy.
6. Пошуковики: [Google Search Console](https://search.google.com/search-console)
   і [Bing Webmaster Tools](https://www.bing.com/webmasters) → додайте сайт →
   подайте `https://ваша-адреса/sitemap-index.xml`.

Власний домен (наприклад, `berezhany-archive.org.ua`): **Vercel → Settings →
Domains**, потім змініть `url` у `site.config.ts`.

## Крок 7. Перевірте прев'ю в соцмережах

Вставте посилання на будь-яку галерею в
[Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) і
надішліть боту [@WebpageBot](https://t.me/WebpageBot) в Telegram — має
показатися назва, опис і банер галереї.

## Ідеї для інших варіантів архіву

Шаблон підходить не лише для міста:

| Варіант | Що змінити |
|---|---|
| **Село чи громада** | `home` — назва села; галереї — вулиці, школа, храм, родини |
| **Район/область** | кожне місто — окремі галереї; `regionOverrides` для сусідніх областей; карта покаже всю територію |
| **Школа, університет, підприємство** | «Історія» — роки існування; «Люди» — випускники, вчителі, директори |
| **Родинний архів** | галереї за поколіннями чи подіями; «Люди» — члени родини; сайт можна закрити від пошуку (`<meta name="robots" content="noindex">` у `Layout.astro`) |
| **Тематичний** (дерев'яні церкви, замки, вокзали) | `home` — центр регіону; галерея = один об'єкт з точкою на карті |
| **Музей чи бібліотека** | галереї — колекції; «Бібліотека» — фонди з посиланнями на каталог |

Епохи фільтра (`ERAS` і `erasOf` у `src/lib/site.ts`) за потреби легко змінити,
наприклад для архіву XX століття поділити на десятиліття.

## Якщо щось не працює

- **Сайт на Vercel без фото** — не ввімкнено Git LFS (крок 6.3) або фото
  закомічені до `git lfs install`. Перевірка: `git lfs ls-files` має показувати фото.
- **`npm run check` скаржиться на файл** — подивіться формат у README →
  «Формат галереї»; найчастіше це лапки без `\"` або неправильний відступ.
- **Не знайшлися координати міста** — введіть їх вручну (правий клік на
  openstreetmap.org → «Показати адресу»).
- Інші питання — README → «Часті проблеми».
